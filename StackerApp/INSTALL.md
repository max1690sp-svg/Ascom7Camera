# Инструкция по установке и использованию UVC Stacker для PHD2

## Предварительные требования

1. **Windows 10/11 x64** - приложение работает только на Windows
2. **.NET 8.0 Runtime** - скачать с https://dotnet.microsoft.com/download/dotnet/8.0
3. **ASCOM Platform 7** - скачать с https://ascom-standards.org/
4. **Visual Studio 2022** (опционально) - для сборки из исходников

## Установка готовой версии

### Шаг 1: Сборка приложения

```bash
cd StackerApp
dotnet build -c Release
```

### Шаг 2: Регистрация ASCOM-драйвера

Запустите PowerShell **от имени администратора** и выполните:

```powershell
.\RegisterDriver.ps1
```

Или вручную через regasm:

```cmd
regasm /codebase Stacker.ASCOM\bin\Release\net8.0-windows\Stacker.ASCOM.dll
```

### Шаг 3: Запуск приложения

```bash
dotnet run --project Stacker.UI\Stacker.UI.csproj -c Release
```

Или создайте ярлык для `Stacker.UI.exe` после публикации.

## Публикация как отдельного EXE

```bash
dotnet publish Stacker.UI\Stacker.UI.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

После этого в папке `publish` появится готовый к запуску exe-файл.

## Подключение камеры

1. Запустите UVC Stacker
2. В разделе "Настройки камеры":
   - Нажмите "Обновить список" для обнаружения камер
   - Выберите вашу UVC-камеру
   - Выберите режим (разрешение и формат)
   - Нажмите "Подключить"
3. Настройте выдержку и усиление при необходимости
4. Выберите режим сложения (Сумма или Среднее)

## Подключение в PHD2

1. Запустите PHD2
2. В окне подключения оборудования:
   - Тип камеры: **ASCOM**
   - Нажмите кнопку выбора рядом с полем камеры
   - В ASCOM Chooser найдите **"UVC Stacker Camera"**
   - Выберите и нажмите OK
3. Нажмите "Connect" в PHD2

## Настройка параметров

### Рекомендуемые настройки для начала

- **Режим сложения**: Сумма (лучше для слабых звёзд)
- **Разрешение**: 640x480 или 800x600 (выше FPS)
- **Выдержка камеры**: минимальная (для максимального FPS)
- **Усиление**: среднее значение

### Экспозиция в PHD2

PHD2 сам управляет длительностью экспозиции через ASCOM. 
Типичные значения для гидирования: 1-3 секунды.

Приложение автоматически накопит нужное количество кадров 
за запрошенное время.

## Проверка работы

### Тестовый режим (симулятор)

Для тестирования без физической камеры можно использовать 
симулятор (требуется модификация кода).

### Проверка ASCOM

Используйте **ASCOM Diagnostics Tool**:
1. Запустите ASCOM Diagnostics
2. Выберите "UVC Stacker Camera"
3. Проверьте свойства и методы
4. Протестируйте StartExposure/ImageReady

## Устранение проблем

### PHD2 не видит камеру

1. Проверьте, что драйвер зарегистрирован:
   ```powershell
   Get-ItemProperty HKCU:\Software\ASCOM\ -ErrorAction SilentlyContinue
   ```
2. Перезапустите PHD2 после регистрации драйвера
3. Убедитесь, что ASCOM Platform 7 установлен

### Нет кадров с камеры

1. Проверьте подключение камеры в Диспетчере устройств
2. Убедитесь, что камера не используется другим приложением
3. Попробуйте другой режим (разрешение/формат)

### Ошибки при экспозиции

1. Не меняйте ROI/binning во время экспозиции
2. Дождитесь завершения текущей экспозиции перед изменением настроек
3. Проверьте логи приложения

## Отмена регистрации

Для удаления драйвера из системы:

```powershell
# От имени администратора
.\UnregisterDriver.ps1
```

## Архитектура приложения

```
┌─────────────────┐     ┌──────────────────┐     ┌──────────────┐
│    PHD2         │────▶│  ASCOM Camera    │────▶│ FrameStacker │
│  (Guider app)   │◀────│    Driver        │◀────│              │
└─────────────────┘     └──────────────────┘     └──────┬───────┘
                                                        │
┌─────────────────┐     ┌──────────────────┐           │
│   UI (WPF)      │────▶│ CameraController │◀──────────┘
│  (MainWindow)   │     │   (UVC/Tests)    │
└─────────────────┘     └──────────────────┘
```

- **CameraController** - единый модуль захвата для UI и ASCOM
- **FrameStacker** - потокобезопасное накопление кадров
- **ASCOM Camera** - обёртка для совместимости с PHD2

## Временная модель

```
PHD2: StartExposure(2000ms)
         │
         ▼
Stacker: Начало накопления свежих кадров
         │
         ├─► Кадр 1 (t=0ms)
         ├─► Кадр 2 (t=33ms)
         ├─► Кадр 3 (t=66ms)
         │   ...
         └─► Кадр N (t=2000ms)
         
         ▼
       FinishExposure → ImageReady
         │
         ▼
PHD2: ImageArray (получение данных)
```

Важно: каждый запрос StartExposure получает собственные кадры,
начиная с момента вызова. Старые кадры не используются.
