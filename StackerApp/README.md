# UVC Stacker для PHD2

Приложение-посредник между USB UVC-камерой и PHD2, которое накапливает короткие кадры и предоставляет результат через виртуальную ASCOM-камеру.

## Требования

- Windows 10/11 x64
- .NET 8.0 Runtime
- ASCOM Platform 7
- OpenCvSharp4

## Сборка

```bash
cd StackerApp
dotnet build -c Release
```

## Установка драйвера

После сборки необходимо зарегистрировать ASCOM-драйвер в системе:

```bash
# Регистрация COM-компонента
regasm /codebase Stacker.ASCOM/bin/Release/net8.0-windows/Stacker.ASCOM.dll

# Или вручную через PowerShell с правами администратора:
.\RegisterDriver.ps1
```

## Запуск приложения

```bash
dotnet run --project Stacker.UI/Stacker.UI.csproj -c Release
```

## Подключение в PHD2

1. Запустите UVC Stacker
2. Выберите камеру и режим
3. Нажмите "Подключить"
4. В PHD2 выберите камеру типа ASCOM
5. Найдите "UVC Stacker Camera" в списке
6. Подключитесь

## Структура проекта

- **Stacker.Core** - Базовые интерфейсы и логика захвата/накопления
- **Stacker.UI** - Оконный интерфейс на WPF
- **Stacker.ASCOM** - Виртуальная ASCOM-камера

## Режимы работы

### Сумма (по умолчанию)
Складывает значения пикселей всех кадров. Увеличивает сигнал, но может привести к насыщению.

### Среднее арифметическое
Усредняет кадры. Сохраняет динамический диапазон, но требует больше вычислений.

## Важные замечания

- Не меняйте настройки ROI или binning во время экспозиции
- Для цветных камер используется конвертация в монохромное изображение
- Размер пикеля по умолчанию 5 мкм - измените при необходимости
- Камера не поддерживает пульс-гидирование через порт камеры

## Отладка

Для проверки ASCOM-совместимости используйте ASCOM Diagnostics Tool.
